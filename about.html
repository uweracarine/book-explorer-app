About Book Explorer

A modern, responsive book browsing web app

📖 What is Book Explorer?

Book Explorer is a fully responsive, multi-page web application that lets you search and discover books using the free Open Library API — a catalogue of millions of titles.

Search for any title, author, or topic. Save the books you love to your personal Favourites list. Your favourites are stored in your browser's localStorage, so they persist between sessions with no account needed.

Built as part of a front-end development lab series covering responsive layouts, DOM interactivity, ES6 modules, async JavaScript, and API integration.

🛠 Tech Stack

🌐 HTML5
🎨 CSS3
⚡ Vanilla JS
📦 ES6 Modules
📚 Open Library API
💾 localStorage
🔤 Google Fonts
🌙 Dark Mode

✦ Features

  • Search millions of books via the Open Library API
  • Responsive grid — 1 col mobile → 2–3 tablet → 4 desktop
  • Add / remove favourite books with one click
  • Favourites persist across page refreshes via localStorage
  • Toast notifications on add / remove
  • Dark mode toggle — preference saved between sessions
  • Loading spinner and "No results" feedback
  • Sticky frosted-glass navbar
  • Responsive mobile hamburger menu
  • XSS-safe HTML rendering

🚀 How to Run Locally

Because the app uses ES6 modules and fetches from an external API, you need a local HTTP server (not file://).

# Option 1 — Node.js (npx)
npx serve .

# Option 2 — Python
python -m http.server 8080

# Option 3 — VS Code
Install the "Live Server" extension, then
right-click index.html → Open with Live Server

Then open http://localhost:3000 (or the port shown) in your browser.
